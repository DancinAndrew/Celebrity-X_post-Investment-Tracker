# 分類判準

這份文件是**判準的唯一權威來源**。分類器提示詞、交接說明與評測裁決都引用它。
要改判準改這裡，然後同步 `scripts/x_consensus/x_consensus/classify.py` 的
`SYSTEM_PROMPT` 並把 `PROMPT_VERSION` 加一。

> 換判準等於換分類標準，舊訊號不能跟新訊號混著算共識。
> 所以每次改都要換 `classifier_version`。

## 核心分界：立場 vs 語氣

| | 立場 stance | 語氣 tone |
|---|---|---|
| 值 | bullish / bearish / unclear | positive / negative / neutral |
| 進共識計算 | **是** | 否，只顯示 |
| 標準 | 從嚴 | 可從寬 |
| 問題 | 作者認為這檔股票會怎樣？ | 這則提及對這家公司讀起來是正面還負面？ |

分成兩欄的理由見下面第一條裁決。

## 裁決紀錄

### 1. 嘲諷產品不算看空股票（2026-09-11 定）

**問題**：2026-09-10 蘋果發表會當天，四個意見帳號用不同方式酸摺疊機——
Jukan 說「怎麼這麼醜」，大老师說「來看蘋果跳水了」，Ren 貼微軟 Surface Duo 反諷，
Michael Sikand 承認自己看多判斷錯了。這些算不算看空蘋果？

**裁決**：立場一律 `unclear`，語氣標 `negative`。

**理由**：如果去問這幾位「你看空蘋果嗎」，多半會說我只是在酸產品。
把它算成看空會製造出**不存在的共識**，而這正是這個工具最致命的失效模式——
整個價值建立在「這 N 個獨立的人意見一致」上，一旦共識是製造出來的，
工具就變成反指標。而且失效方式有偏差：新聞週期讓所有人同一天談同一家公司，
剛好是假共識最容易成形的時候。

**代價不對稱**：漏掉一個弱訊號，成本是「僅提及」區少一行。
無中生有一個三帳號看空共識，成本是一個錯的結論。

**但單純判 unclear 會掉資訊**：四個人公開嘲諷旗艦產品的一天，
報告上顯示「無人對蘋果表態」，這也不對。所以才拆出語氣欄，
在共識分母外面單獨顯示。兩邊都不犧牲。

**實測影響**（2026-09-10 資料）：兩種判準下沒有任何個股換區，
但蘋果的呈現從「無人明確表態」變成「三個帳號看空」。
差別不在分類結果，在讀報告的人會得到什麼結論。

### 1b. 語氣的預設值與顯示範圍（2026-09-11 定）

語氣預設由立場推導：bullish → positive、bearish → negative、unclear → neutral。
只有需要特別標記的情況才手動指定，例如「立場 unclear 但語氣 negative」的嘲諷。

報告的「語氣訊號」區塊**只取立場為 unclear 的訊號**。
已經有明確立場的個股會出現在共識區塊，在語氣區重印一次只是噪音；
這一區存在的意義是補共識看不見的東西。

語氣要寫在答案檔（`.data/handoff/answers_*.json`）裡，不能只改資料庫。
答案檔才是那次分類的來源，只改資料庫的話下次重跑 `handoff apply` 會被洗掉。

### 2. 帳號類型決定判讀寬嚴

- `opinion`：正常判立場。
- `options_flow`：純數據播報給 unclear；作者有表達傾向才給方向。
- `market_news`：轉述一律 unclear，除非作者加了自己的判斷。
- `trade_disclosure`：一律 unclear。揭露別人的交易不是作者的觀點。

只有 `opinion` 進共識分母，其餘三類不投票。

### 3. 立場是貼文層級，不做帳號層級淨值

同一帳號同一天可以對同一檔既看多又看空——Michael Sikand 2026-09-10
對蘋果盤中三度改口就是實例。這種情況記為 `mixed`，不壓成單一淨值。
把翻轉過程壓平會丟掉「這個人今天很猶豫」這個訊息。

### 4. 沒提到不等於中立

從未提及該檔的帳號列為 `not_mentioned`，不進共識分母。
把沉默當成中立票會稀釋真正的共識強度。

### 5. 清單型貼文不產生訊號

一篇列出大量代碼的貼文（例如「所有單字母代碼一覽」列了 25 檔）
標記 `is_list_or_market_wide`，不產生任何訊號。那是資料不是觀點。

### 6. 代碼解不出來就不猜

模型只負責判立場，不負責決定「這是哪一檔」。
代碼對應交給 `tickers.resolve` 這層確定性邏輯；解不出來的進 unresolved
等人工補別名。六碼數字在韓國、上海、深圳都存在，猜錯會靜默地把訊號歸到錯的公司。
